# Баг-репорт: Маскирование таймаута источника начислений под успешный нулевой результат

## Паспорт дефекта
* **ID дефекта:** BUG-AI-01
* **Заголовок:** При таймауте сервиса начислений ЖКХ адаптер подменяет статус ошибки на `ok` с пустым списком данных, приводя к дезинформации пользователя о «0 начислений»
* **Компонент:** `@librechat/agents@3.9.8` / `src/adapter.ts`
* **Версия датасета:** 1
* **Версия агента:** 1
* **Критичность:** Critical / Blocker (Бизнес-критичный дефект)
* **Приоритет:** P0 (Блокирует выпуск в продуктив)
* **Автор:** Павел Котляров (kotlyarov-qa)
* **Связанный автотест:** `tests/test_agent_api.py::test_08_EDUCATIONAL_DEFECT_timeout_masks_as_ok`

---

## Предусловия
1. Сервисы стенда развернуты в Docker (`docker compose up -d`).
2. Сессия авторизации пользователя: `demo-alice` (лицевой счет `10001`).
3. Источник начислений переведен в режим симуляции таймаута: `tool_mode: timeout`.

---

## Шаги воспроизведения

### Способ 1 (через API):
Выполнить POST-запрос к эндпоинту агента:
```bash
curl -X POST http://localhost:8092/run \
  -H "Authorization: Bearer demo-alice" \
  -H "Content-Type: application/json" \
  -d '{"message":"Начисления 10001 за 2026-08","mode":"mock","tool_mode":"timeout"}'
```

### Способ 2 (через веб-интерфейс LibreChat):
1. Открыть `http://localhost:3082`.
2. Выбрать модель **alice-timeout → interview-mock**.
3. Отправить в чат: `Начисления 10001 за 2026-08`.

## Ожидаемый результат (по спецификации CONTRACT.md и qa.pdf)
* Правило контракта: *«Таймаут, ошибка и запрет доступа не означают нулевые начисления. Источник недоступен: Пользователь получает понятное сообщение о невозможности проверки, а не выдуманные суммы или успешный пустой результат»*.
* Агент фиксирует статус `timeout` от инструмента и сообщает жителю:
  > *«Невозможно получить начисления: timeout. Сервис временно недоступен, повторите попытку позже»*.

---

## Фактический результат
1. Инструмент возвращает сырой статус `source: { status: "timeout", message: "Source timed out" }`.
2. Функция `adaptCharges()` в файле `src/adapter.ts` перехватывает таймаут и мутирует его в успешный пустой результат:
   ```typescript
   // src/adapter.ts:3
   if (result.status === 'timeout') return { status: 'ok', data: [] };
   ```
3. Модель получает статус `ok` и генерирует ложное подтверждение:
   > *«Счёт 10001, период 2026-08. Начислено 0 коп. Источник успешно прочитан.»*

## Доказательство по трассе (Trace из `artifacts/runs.jsonl`)

Цепочка вызовов: `Запрос -> Вызов get_account -> Вызов get_charges -> Ответ источника -> Итог агента`:

```json
{
  "run_id": "68c317b4-b639-4712-a691-a0452cd69512",
  "tool_mode": "timeout",
  "events": [
    {
      "name": "get_account",
      "args": { "account_number": "10001" },
      "source": { "status": "ok", "data": { "id": "acc-alice", "account_number": "10001" } },
      "result": { "status": "ok", "data": { "id": "acc-alice", "account_number": "10001" } }
    },
    {
      "name": "get_charges",
      "args": { "account_id": "acc-alice", "period": "2026-08" },
      "source": {
        "status": "timeout",
        "message": "Source timed out"
      },
      "result": {
        "status": "ok",
        "data": []
      }
    }
  ],
  "answer": "Счёт 10001, период 2026-08. Начислено 0 коп. Источник успешно прочитан."
}
```

**Ключевая аномалия в трейсе:**
* В поле `source`: `"status": "timeout"`
* В поле `result`: `"status": "ok", "data": []`
* Разрешение ошибки произошло не на стороне LLM, а на уровне адаптера до передачи данных в контекст модели.

## Влияние на бизнес (Business Impact)
1. **Финансовые потери УК / ЖКХ:** Жители, запросившие начисления в момент пиковой нагрузки или сбоя базы, получают ответ об отсутствии задолженности (0 руб.), не оплачивают квитанции вовремя, что влечет кассовый разрыв.
2. **Претензии и штрафы:** Пользователям впоследствии начисляются пени за неуплату, что вызывает массовые жалобы в надзорные органы (ГЖИ, Роспотребнадзор).
3. **Потеря доверия к AI-ассистенту:** Системный обман пользователей делает невозможным использование бота как доверенного источника биллинговой информации.

## Вердикт теста
Команда запуска автотестов возвращает ненулевой код (Exit Code 1):
```text
FAILED tests/test_agent_api.py::test_08_EDUCATIONAL_DEFECT_timeout_masks_as_ok
AssertionError: [УЧЕБНЫЙ ДЕФЕКТ ОБНАРУЖЕН]: adapter.ts подменил статус 'timeout' на 'ok' с пустым списком data: []!
```
Релиз сценария **категорически блокируется** до исправления функции `adaptCharges()`.
