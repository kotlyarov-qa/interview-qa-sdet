# Skill: Разбор сбоя по трассе (analyze-trace)

## Назначение
Используется coding agent для расследования причин падения теста или некорректного ответа агента путем анализа цепочки вызовов в JSONL-логах (`artifacts/runs.jsonl`).

## Порядок разбора инцидента:
1. **Поиск записи:**
   Найти запись по `run_id` или последнему запуску в `artifacts/runs.jsonl`.
2. **Анализ цепочки: `запрос -> вызов инструмента -> ответ/ошибка -> итог агента`:**
   - Шаг 1: Проверить входящий промпт `message` и режим `tool_mode`.
   - Шаг 2: Проверить аргументы первого инструмента (например, `get_account(account_number)`).
   - Шаг 3: Сопоставить поле `source` и поле `result` каждого события.
     *Если `source.status != result.status`, зафиксировать факт искажения данных промежуточным адаптером!*
   - Шаг 4: Проверить финальный текст `answer` модели на галлюцинацию или противоречие исходным данным `source`.
3. **Формирование вывода:**
   Указать, на каком именно уровне произошел сбой:
   - Внешний источник (реальный таймаут / ошибка).
   - Адаптер тулов (`src/adapter.ts`).
   - Модель (галлюцинация, игнорирование промпта, prompt injection).
